# dragon-email Color Palette

Built around the app icon's two blues: **Dragon Blue #0F4C9E** and **Sky Wing #4FB3F6**.

## Core brand

| Role | Color | Use |
|---|---|---|
| Primary | `#0F4C9E` (Dragon Blue) | Top bar, primary buttons, selected folder |
| Primary hover | `#0B3C7E` | Button hover and pressed states |
| Accent | `#4FB3F6` (Sky Wing) | Unread dots, focus rings, links on dark backgrounds |
| Accent tint | `#E6F3FE` | Selected email row, hover highlight |

## Light theme

| Role | Color |
|---|---|
| App background | `#F5F8FC` |
| Panels and cards | `#FFFFFF` |
| Borders and dividers | `#DCE4EE` |
| Main text | `#1A2433` |
| Secondary text (dates, previews) | `#5B6B80` |

## Dark theme

| Role | Color |
|---|---|
| App background | `#0E1520` |
| Panels | `#162132` |
| Borders | `#26344A` |
| Main text | `#E8EEF6` |
| Secondary text | `#9AABC0` |
| Primary | `#4FB3F6` (deep blue is too dark here, so use the sky blue) |

## Status and signature colors

| Role | Color | Notes |
|---|---|---|
| Fire Orange (signature accent) | `#F2762E` | Used sparingly: flagged or important mail, the compose button. It ties into the dragon idea. |
| Success | `#1E9E6A` | Sent, saved |
| Warning | `#E0A400` | Large attachments, unverified sender |
| Error | `#D64545` | Failed to send, phishing warnings |

## Ways to combine them

- **Calm professional:** mostly white and light gray, with Dragon Blue only for the top bar and primary buttons. This is the closest to the Outlook feel.
- **Bold brand:** a Dragon Blue sidebar with white text, Sky Wing for the selected folder, and a white reading pane.
- **Dragon accent:** either of the above, plus Fire Orange for the Compose button and flagged mail, which gives the app a recognizable personality.

## Accessibility note

All the text colors above pass contrast requirements against their backgrounds. One exception: Sky Wing `#4FB3F6` is too light for text on white, so on light backgrounds use it only for icons, dots and focus rings.
